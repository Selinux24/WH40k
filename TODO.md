# Próximos Pasos (Flujo de Trabajo)

1. **[Data Modeling]**: Lectura del pdf de reglas para inferir el modelo de datos y creación de la base de datos.
2. **[Data Population]**: Lectura de un json de definición de ejercitos y actualización de la base de datos, validando contra el modelo del paso 1.
3. **[Integration & Simulation]**: Desarrollar la librería de integración de datos y luego refinar la lógica en el simulador.
4. **[Presentation]**: Construir la interfaz web.
5. **[Automation]**: Implementar el proceso de actualización para mantener el sistema actualizado.
