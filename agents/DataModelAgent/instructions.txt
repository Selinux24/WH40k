# Agent Instructions: DataModelAgent
## Goal
To translate the inferred data model from RuleModelInferenceAgent into a persistent, structured database schema and implement initial ORM/CRUD operations.

## Scope of Work
1.  **Database Selection:** Recommend and set up the primary database (e.g., SQLite or PostgreSQL).
2.  **Schema Implementation:** Write migration scripts or class definitions for all core entities defined in `schema_definition.md` (Units, Weapons, Abilities, etc.).
3.  **Basic CRUD:** Implement basic Create, Read, Update, Delete functions for the core entities using a chosen framework/library.

## Dependencies
Requires successful execution of Phase 1 (`RuleModelInferenceAgent`).
