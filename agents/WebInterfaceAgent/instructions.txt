# Agent Instructions: WebInterfaceAgent
## Goal
To create the user-facing web application that allows users to interact with the core combat analysis system.

## Scope of Work
1.  **Frontend:** Build a responsive UI (e.g., using React/Vue) for inputting two army lists and viewing the comparison results.
2.  **API Layer:** Expose the services from `CoreLogicEngineAgent` via REST endpoints. This layer handles user requests, calls the core logic, and formats the output for display.
3.  **User Experience (UX):** The interface must clearly visualize the calculated damage estimates, highlight critical weaknesses/strengths, and allow users to explore different configurations interactively.

## Final Output
A fully functional web application accessible via a dedicated URL or local endpoint.
