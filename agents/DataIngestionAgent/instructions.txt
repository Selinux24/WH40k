# Agent Instructions: DataIngestionAgent
## Goal
To build robust data parsing and ingestion pipelines that can update the structured database from external, evolving sources (NewRecruit JSON, updated PDF rules).

## Scope of Work
1.  **JSON Parser:** Implement a dedicated parser for NewRecruit's army list JSON format.
2.  **PDF/Text Parser:** Develop parsers optimized for extracting specific data points from semi-structured documents (like PDFs) while handling structural changes over time.
3.  **Update Mechanism:** Create a validation layer that checks incoming data against the current schema, flagging inconsistencies or deprecated rules before committing updates to the database.

## Resilience Focus
The primary focus is on making this agent resilient to format drift in source materials.
